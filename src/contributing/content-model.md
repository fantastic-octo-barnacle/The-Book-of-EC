# 内容模型

## 学习节点

节点是学习图和正文的唯一基本单位。一个节点对应一个目录，元数据由目录中的 `meta.ts` 声明；全部 Markdown 页面都必须登记在 `parts` 中。

节点之间只有两种关系：

- `required`：缺少它会妨碍当前节点建立正确模型。
- `recommended`：有助于理解，但可以并行或稍后补充。

必需关系不得成环。全书不定义统一线性顺序。

## 节点内部页面

一个多页节点的内部页面一定是线性的。`parts` 首项是入口页，其余页面按数组顺序生成侧栏和翻页。每项的 `path` 是包含 `.md` 扩展名的相对文件路径；生成页面链接时会移除扩展名。

页面名称不预设为“原理、示例、练习、实验”；作者应根据内容边界命名。

## 专题

专题是节点集合形成的子图，不是章节序列。一个节点可以属于多个专题，专题成员数组的书写顺序没有学习语义。

专题图会弱化显示成员节点的直接外部先修，以免隐藏关键边界。
