# 电路与电平基础

## 本章要点

电控组的工作（嵌入式软件）是相对底层的工作。在实际编写软件时，我们常常会遇到如：晶振频率，外设引脚接口的配置等与硬件息息相关的问题。因此认识基本的电路元件，了解它们的基本特性，学会根据原理图等资料获取在嵌入式软件编写过程中需要的信息，不仅能有效提升软件编写的效率，还能够加深我们对软件的理解。

在本章，你将掌握一下要点：

- 基本元器件的辨识
- 数字逻辑电路中简单的名词缩写及其含义
- 多种通信的电平协议

## 基本元器件的辨识

由于实际工程中涉及到的元器件种类繁多，难以在此一一罗列，因此仅介绍最重要的晶振。其余基本元器件需要自行了解。

### 单片机时钟与晶振

时钟信号是维持时序逻辑的重要手段。对于现代复杂计算机系统而言，维持时序逻辑的基础便是时钟信号。简单来讲，时钟信号是计算机的心跳，没有时钟，计算机就无法运行。

> 拓展内容：[为什么计算机离不开时钟](#时序逻辑)

单片机的常用时钟信号有如下几种:

| 类型               | 复杂度                                                       | 精准度                           |
| ------------------ | ------------------------------------------------------------ | -------------------------------- |
| 内部 RC 振荡器     | 无需外部元件，仅靠内部元件即可完成                           | 较低                             |
| 外部振荡器（晶振） | 需要外围晶振电路，但实现相对简单                             | 较高                             |
| 外部数字时钟信号   | 由外部设备提供时钟信号，更加灵活自由，但外围电路可能更加复杂 | 与外部设备相关，可以达到极高精度 |

晶振通常指利用石英晶体谐振特性产生稳定频率的时钟源。工程中常见两类器件：

- **无源晶体（Crystal）**：本体只有晶体谐振器，需要 MCU 内部振荡器和外部负载电容共同起振。
- **有源晶振/时钟振荡器（Oscillator）**：器件内部已经包含振荡电路，通常有电源、地和时钟输出引脚。它输出的是数字时钟信号，接到 MCU 的外部时钟输入脚即可。

无源晶体的典型原理图如下。实际项目中，引脚名称可能写作 `OSC_IN` / `OSC_OUT`、`HSE_IN` / `HSE_OUT` 或芯片手册指定的其它名称。

- 电压是两点间的量；测量与通信需要明确参考地。
- 逻辑高低电平必须满足双方输入输出阈值。
- 电源额定电压之外，还需关注电流、纹波、极性和上电过程。

### 时序逻辑

数字电路大致可以分为两类:

- 组合逻辑（Combinational Logic）
- 时序逻辑（Sequential Logic）

逻辑信号通过逻辑门时会有传播延迟（propagation delay），如果在上次逻辑信号还没完全计算完成时就开启下一轮计算，就会产生错误。
借助设置大于传播延迟的时序，我们可以保证上次计算完成后再开启下一次计算。

同时，在复杂逻辑门系统中，可能出现多个逻辑门操作同一个状态寄存器的情况。这就会产生竞争，即不同电路读取或写入的数据会对其它电路产生影响。由于设计制造、老化程度等原因，不同逻辑门的传播延迟不同且会出现波动，这种影响可能是随机的。

假设逻辑门 D1 需要读取寄存器 R1 的数据，将结果存在 R2 中；逻辑门 D2 需要读取寄存器 R2 的数据，将结果存在 R1 中。这样，我们就构建了了一个交叉耦合的闭环（类似基本的RS锁存器或SRAM存储单元）。
因为没有时钟或优先级控制，这个电路运行一次的结果，完全取决于D1和D2谁先完成“读取-计算-写入”这个完整链条。
避免这种问题有很多方法，在现代计算机系统中，常用的方法便是采用时钟同步，即让不同逻辑门仅在时钟信号触发时计算，这既防止了寄存器读写竞争，还让复杂逻辑电路的设计变得简单。
