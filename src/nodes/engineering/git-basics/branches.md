# 分支

分支用于在同一个仓库中保留不同的工作方向。你可以让 `main` 保持在已经验证的状态，同时在另一个分支尝试新功能；这些修改不会因为存在于同一个仓库就立即进入 `main`。

## 【自主学习】

Git 的分支操作非常丰富。在本节中，请完成 [Learn Git Branching](https://learngitbranching.js.org/?locale=zh_CN) 中的以下章节：

- 基础篇（Introduction Sequence）
- 高级篇（Ramping Up）

::: warning 注意
Learn Git Branching 主要用于学习和练习 Git 的分支操作，它的界面和命令与 Git 的实际使用略有不同，例如，它忽略了提交 commit 的具体步骤。请在练习时注意区分。
:::
