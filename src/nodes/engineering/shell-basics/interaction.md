# 交互式 Shell 的基本操作

交互式 Shell 会在提示符后等待输入。按 Enter 后，Shell 才会解析并执行当前命令行。在此之前，可以编辑、补全或取消输入。

本页介绍 PowerShell、Bash 和 Zsh 常见默认配置下的操作。快捷键可以由 Shell、行编辑器或终端重新配置；如果实际行为不同，应以当前环境的帮助和配置为准。

## 编辑当前输入

在按 Enter 之前，当前命令行只是一段可编辑文本：

| 按键       | 常见作用                     |
| ---------- | ---------------------------- |
| 左右方向键 | 在当前命令行中移动光标       |
| Backspace  | 删除光标左侧的字符           |
| Delete     | 删除光标处的字符             |
| Ctrl+C     | 取消当前输入，回到新的提示符 |

例如，先输入 `git --versoin`，但不要按 Enter。用左右方向键移动光标，再用 Backspace 或 Delete 将其修正为 `git --version`。按 Enter 后应输出 Git 版本。

再输入 `git status`，不按 Enter，直接按 Ctrl+C。应当出现一个新的提示符，而 `git status` 没有被执行。

## 使用 Tab 补全

输入命令名或路径的前几个字符后，按 Tab 可以请求 Shell 补全。补全能减少重复输入和拼写错误，但不会代替执行前的检查。

输入 `cd `（`cd` 后有一个空格），再按 Tab。根据 Shell 和候选数量，可能出现以下现象之一：

- 直接填入唯一的候选项；
- 列出多个候选项；
- 重复按 Tab 时在候选项之间切换。

观察结果后按 Ctrl+C 取消输入，不要进入用途不明的目录。当路径包含空格等特殊字符时，Shell 可能自动添加引号或转义符；不同 Shell 的结果不必相同。

## 浏览命令历史

上方向键会调出较新的历史命令，下方向键则向较新的方向移动。调出的命令只是当前输入：可以先编辑，只有按 Enter 后才会再次执行。

先执行：

```sh
echo first
```

再按上方向键调出这条命令，把 `first` 改为 `second` 后按 Enter。预期输出为 `second`。

Shell 是否保存跨会话历史、保存在哪里以及保存多少条，取决于 Shell 和配置。不要把密码、令牌等敏感值直接写入命令；应优先使用工具提供的安全输入方式。

## 中断正在运行的程序

前台程序持续运行时，按 Ctrl+C 通常会向它发出中断请求。程序结束后，Shell 重新显示提示符并等待下一条命令。

使用本机回环地址启动持续的 `ping`：

::: code-group

```powershell [PowerShell]
ping -t 127.0.0.1
```

```bash [Bash/Zsh]
ping 127.0.0.1
```

:::

看到多行回复后按 Ctrl+C。输出应当停止，终端重新出现 Shell 提示符。

Ctrl+C 是中断请求，不是强制终止或“撤销”：程序可以处理或忽略它，已经写入的文件、已发送的数据等副作用也不会因此自动恢复。

## 清理显示与退出分页器

Ctrl+L 在常见配置下会重绘提示符，并清理当前显示区域。如果当前配置不支持，可以执行：

::: code-group

```powershell [PowerShell]
Clear-Host
```

```bash [Bash/Zsh]
clear
```

:::

这些操作只改变显示，不会删除命令历史，也不会撤销已执行的命令。

帮助文档或长输出有时会由 `less` 等分页器显示。此时可以用方向键滚动，按 `q` 退出。`q` 是分页器接收的按键，不是需要在 Shell 提示符下执行的命令。如果帮助内容直接输出后结束，则没有进入分页器，不需要按 `q`。
