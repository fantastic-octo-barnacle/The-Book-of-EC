# 命令行基础

## 要点

- 相对路径由当前工作目录解释。
- 进程以退出码报告执行结果。
- `stdin`、`stdout`、`stderr` 是独立通道。

## 检查题

`cmd > out 2>&1` 分别重定向了什么？相对路径为什么会随工作目录改变？

## 延伸

检索：`shell stdin stdout stderr`、`Linux process exit code`。
