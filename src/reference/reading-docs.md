# 如何读技术资料

面对芯片手册、协议规范或开源工程，不要从第一页线性读到最后一页。先带着一个可验证的问题定位。

## 推荐顺序

1. 写出问题：例如“这个定时器时钟实际来自哪里”“CAN 过滤器何时生效”。
2. 先读概览、框图、引脚/电气限制和功能描述，建立对象与数据流。
3. 再查初始化顺序、时序图、寄存器字段和错误条件。
4. 把关键结论换算为本项目的时钟、单位、范围和引脚；最后用测量验证。

## 资料优先级

- 学习起步：中文文章、课程或社区解释，帮助建立直觉。
- 配置与限制：芯片厂商数据手册、参考手册、协议标准、RTOS 官方文档。
- 行为证据：项目源码、示波器/逻辑分析仪记录、最小复现实验。

::: tip
代码示例说明“有人曾如何使用”；参考手册说明“硬件允许什么”；测量说明“你的系统现在发生了什么”。三者缺一不可。
:::
