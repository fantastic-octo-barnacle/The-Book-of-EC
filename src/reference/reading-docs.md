# 如何读技术资料

阅读芯片手册、协议规范或开源工程时，应从可验证的问题出发，而非逐页通读。

## 推荐顺序

1. 定义问题，例如“定时器时钟来自哪里”“CAN 过滤器何时生效”。
2. 阅读概览、框图、引脚/电气限制和功能描述，确定对象与数据流。
3. 查询初始化顺序、时序图、寄存器字段和错误条件。
4. 将结论换算为本项目的时钟、单位、范围和引脚，并以测量验证。

## 资料优先级

- 学习起步：中文文章、课程或社区解释，帮助建立直觉。
- 配置与限制：芯片厂商数据手册、参考手册、协议标准、RTOS 官方文档。
- 行为证据：项目源码、示波器/逻辑分析仪记录、最小复现实验。

::: info
示例代码说明用法；参考手册规定约束；测量反映实际行为。三者不能互相替代。
:::
