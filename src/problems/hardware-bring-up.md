# 硬件与上电

::: danger 安全边界
首次上电应限流并隔离高功率执行器；未知短路、异常发热或错误极性必须先断电。
:::

| 现象              | 首要观测                         | 排查边界                                   | 相关节点                                                                                       |
| ----------------- | -------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| 板子无法上电      | 输入电压、电源轨、电流和温升     | 电源是否到达并满足器件工作条件             | [电路与电平基础](/nodes/embedded/circuit-basics/)、[板级上电与启动](/nodes/robotics/bring-up/) |
| 无法下载或启动    | 复位、启动脚、调试接口和时钟     | 调试连接、复位状态与应用执行是否被混为一谈 | [时钟、复位与启动](/nodes/embedded/clock-reset/)、[板级上电与启动](/nodes/robotics/bring-up/)  |
| GPIO 没有预期电平 | 引脚实际波形、模式、上下拉和复用 | 芯片配置、板级连接与外部负载               | [GPIO 与引脚复用](/nodes/embedded/gpio/)                                                       |
| 外设无响应        | 时钟、引脚、片选或地址和原始波形 | 外设硬件状态与上层 API 返回值              | [外设驱动边界](/nodes/embedded/drivers/)、[中断与事件响应](/nodes/embedded/interrupts/)        |
