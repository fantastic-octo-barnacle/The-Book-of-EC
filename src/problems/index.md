# 我遇到了什么问题？

从现象进入，但不要止于“解决了”。沿链接回到原理页，补齐下一次能自行定位所需的模型。

- [程序与构建问题](/problems/software)：构建失败、改动不生效、程序跑飞、数据异常。
- [硬件、通信与控制问题](/problems/system)：无法上电、无通信、丢包、电机不转、振荡与漂移。

## 先做四件事

1. 写下可重复的现象、版本、输入与环境，而不是解释或猜测。
2. 明确最后一个已知正常的边界：供电、引脚、驱动、数据、控制量或执行器。
3. 选择能区分两种假设的最小观测。
4. 修复后用反例或回归测试确认，不以“暂时好了”为结论。
