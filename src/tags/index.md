# 标签

节点不使用平铺标签。分类由受控的“概念”和“技术”两类词表承担；专题是独立的阅读集合，不属于标签。

## 概念 `concepts`

表示可迁移的原理或技术对象，例如 `interrupt`、`lifetime`、`feedback`、`frame`、`synchronization`。概念用于关联不同专题中的同类原理。

## 技术 `technologies`

表示具名语言、平台、协议、工具或项目环境，例如 `C`、`STM32`、`FreeRTOS`、`CAN`、`RoboMaster`。

## 学习层级 `level`

- `intro`：建立基础模型。
- `core`：后续节点会频繁使用的模型。
- `advanced`：需要已有基础，涉及实现边界或取舍。
- `integration`：将多个节点用于系统或项目。

层级用于筛选和配色；真正的学习顺序由依赖关系决定。

## 不属于标签的内容

- [专题](/collections/)：人工维护的阅读集合，允许节点重复出现。
- 依赖关系：`required` 和 `recommended` 定义学习前提。
- [问题索引](/problems/)：从故障现象进入相关节点。
