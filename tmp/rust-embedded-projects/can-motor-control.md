# 方向项目：CAN 电机速度闭环

## 项目目的

使用 RoboMaster Type C 开发板，通过 CAN 驱动实际提供的电机，并实现按键切换目标转速的单速度闭环。项目用于练习 Embassy 外设使用、协议研究、反馈控制、硬件调试和软硬件逻辑分离。

## 提供资源

- RoboMaster Type C 开发板，MCU 为 STM32F407IGH6；
- 一套可通过 CAN 驱动的电机及其驱动器；
- CAN 收发、电源、按键和调试所需器材；
- 经过检查的最小 Type C 工程脚手架。

电机和驱动器型号在任务发放时填写：`____________`。

脚手架只包含 Cargo、编译目标、链接和 probe-rs 基本配置，不包含日志、GPIO、CAN、按键或其他外设初始化。协议资料、数据手册、接线方式、总线参数和安全限制由学员自行查找并核对。

## 安全约束

- 首次上电前固定电机和驱动器，避免旋转部件、线缆或负载伤人；
- 使用合适的供电和限流措施；
- 在运行控制代码前确认能够立即断开电机电源；
- 未确认反馈和控制量含义前，不发送大幅值控制指令；
- 软件必须在反馈超时后停止输出。

## 核心目标

- 自行完成时钟、日志、GPIO 和 CAN 初始化；
- 查明所给电机的供电、连接、CAN 位速率、标识符和数据格式；
- 发送合法控制命令，使电机以受限的小输出运行和停止；
- 连续接收并解析电机反馈；
- 将原始字段转换为代码中含义明确的物理量或控制量；
- 输出足以观察目标值、反馈值和控制输出的日志。

除电机规定的 CAN 命令与反馈外，不加入上位机、遥控器或其他通信协议。

## 标准目标

- 实现离散速度 PID，根据电机速度反馈计算控制输出；
- 使用开发板按键在停止、低速正转、高速正转和低速反转等预设目标间切换；
- 明确控制周期，并使 PID 计算使用一致的采样周期；
- 对控制输出进行限幅；
- 反馈超过合理时限未更新时停止输出，并避免恢复通信后突然输出危险控制量；
- 将 PID 实现为不依赖 CAN、GPIO 或具体 MCU 的纯 Rust 模块；
- 为 PID 模块编写单元测试，至少覆盖误差方向、输出限幅和积分行为。

不要求位置环、串级控制、自动整定或高性能控制效果。参数只需在安全范围内使系统呈现稳定、可解释的速度跟随行为。
